Files:
- index.html: the complete responsive website
- assets/profile.jpg: the portrait you supplied

How to publish to GitHub Pages:
1. Open https://github.com/akana-250/niyonkurjeanpierre.github.io
2. Click Add file > Upload files.
3. Upload index.html and the assets folder (including profile.jpg). If the browser does not allow folders, create an assets folder in GitHub first, then upload profile.jpg inside it; upload index.html at the repository root.
4. Commit changes.
5. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for deployment and visit https://niyonkurjeanpierre.github.io/
